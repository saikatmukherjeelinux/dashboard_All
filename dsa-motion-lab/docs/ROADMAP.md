# Full DSA Learning Roadmap

Track each topic with three goals: **explain the concept**, **implement from scratch**, **animate a representative example**. ✅ denotes a lesson available in the website; ⬜ denotes planned coverage.

## 01 · Foundations
- ⬜ Big O, Big Ω, Big Θ and time-space tradeoffs
- ⬜ Recursion, call stack, recursion trees, master theorem
- ⬜ Bit manipulation and binary representations

## 02 · Arrays & strings
- ⬜ Arrays, dynamic arrays, slices and memory layout
- ⬜ Two pointers, sliding window, prefix sums, difference arrays
- ⬜ String matching and KMP

## 03 · Sorting & searching
- ✅ Bubble, selection, insertion sort
- ✅ Linear and binary search
- ⬜ Merge sort, quicksort, heap sort, counting sort, radix sort
- ⬜ Binary search on the answer / rotated arrays

## 04 · Linear structures
- ✅ Stack, queue, singly linked list
- ⬜ Deque, circular queue, doubly linked list
- ⬜ Monotonic stack/queue, next greater element

## 05 · Hash-based structures
- ⬜ Hash tables, collisions, load factor, sets, dictionaries
- ⬜ Frequency maps, 2-sum, grouping and deduplication

## 06 · Trees & heaps
- ✅ Binary search tree insertion
- ⬜ Tree traversals: preorder, inorder, postorder, level-order
- ⬜ AVL/red-black trees, segment tree, Fenwick tree
- ⬜ Min/max heap, priority queue, trie

## 07 · Graphs
- ✅ BFS and DFS
- ⬜ Graph representations, topological sort, cycle detection
- ⬜ Disjoint set union, Kruskal and Prim MST
- ⬜ Dijkstra, Bellman-Ford, Floyd-Warshall, A*

## 08 · Algorithm patterns
- ⬜ Divide and conquer, greedy, backtracking
- ⬜ Dynamic programming: memoization, tabulation, knapsack, LCS
- ⬜ Intervals, sweep line, binary lifting

## 09 · Advanced + interview problems
- ⬜ Tries, suffix arrays and suffix automata
- ⬜ SCC, bridges, articulation points, network flow
- ⬜ Complexity analysis, invariants, correctness proofs
- ⬜ Curated interview questions with input/output tests

Each future lesson can be added as a new metadata entry, a step generator and a Python reference snippet in `assets/app.js`.
